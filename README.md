# 🤖 AI 寫作偵測器 (AI Writing Detector)

[![Streamlit App](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](https://aiot-homework-5-bqy5p4nleevs6jdgof2ybm.streamlit.app)

這是一個使用 Streamlit 建立的互動式網頁應用程式，可以分析英文文本，並判斷其是由 AI 生成還是由人類撰寫。

## ✨ 主要功能

- **高互動性介面**：使用 Streamlit 打造，介面簡潔美觀，操作直觀。
- **支援多種偵測模型**：內建兩種不同的 AI 偵測模型，使用者可以自由切換，比較不同模型的分析結果。
- **兩種分析模式**：
  1.  **單筆文字分析**：直接在輸入框貼上文本進行即時分析。
  2.  **批次檔案分析**：可上傳 `.txt` 檔案，程式會逐行分析並以表格形式呈現所有結果。
- **效能優化**：透過快取 (Caching) 機制，已載入的模型和已分析過的文本結果會被記憶，大幅提升重複操作時的反應速度。
- **輔助功能**：提供一鍵載入 AI 或人類撰寫的範例文字，並可隨時清除內容，方便使用者測試。

## 🔧 安裝與設定

在開始之前，請確保您的電腦已經安裝了 Python (建議 3.8 以上版本)。

#### 1. 複製專案

首先，您需要將此專案下載到您的電腦上。如果您會使用 `git`，請執行：
```bash
git clone <專案的 Git 儲存庫網址>
cd <專案資料夾>
```
如果不會，可以直接下載 ZIP 壓縮檔並解壓縮。

#### 2. 建立虛擬環境 (建議)

為了避免套件版本衝突，建議在獨立的虛擬環境中執行此專案。

```bash
# 建立一個名為 venv 的虛擬環境
python -m venv venv

# 啟用虛v擬環境
# Windows:
venv\Scripts\activate
# macOS / Linux:
source venv/bin/activate
```

#### 3. 安裝所需套件

本專案的所有依賴套件都記錄在 `requirements.txt` 檔案中。請執行以下指令進行安裝：

```bash
pip install -r requirements.txt
```

---

## 🚀 如何執行

當所有套件都安裝完成後，在您的終端機 (Terminal) 中執行以下指令：

```bash
streamlit run app.py
```

執行後，您的預設瀏覽器將會自動開啟一個新分頁，顯示應用程式的介面。

## 🔬 技術詳解 (給新手的說明)

這個部分將詳細解釋 `app.py` 中使用到的主要套件和程式碼邏輯。

### 使用到的核心套件

#### 1. `streamlit`
- **它是什麼？**：一個神奇的 Python 套件，可以讓您用純 Python 腳本快速建立出漂亮的互動式網頁應用，完全不需要懂前端的 HTML, CSS, JavaScript。
- **在這個專案中**：整個應用的使用者介面，包含標題、按鈕、輸入框、分頁、圖表等，都是由 Streamlit 的函式（如 `st.title()`, `st.button()`）建立的。

#### 2. `pandas`
- **它是什麼？**：Python 中最強大的數據分析工具，核心是提供一個叫做 `DataFrame` 的二維表格結構，就像是程式裡的 Excel 表格。
- **在這個專案中**：我們用它來整理要給圖表和表格的資料。例如，建立一個包含 "AI" 和 "Human" 機率的 `DataFrame` 來繪製長條圖，或是在批次分析功能中，將所有結果整理成一個大表格顯示。

#### 3. `transformers`
- **它是什麼？**：由 Hugging Face 公司開發的套件，是通往 AI 自然語言處理 (NLP) 世界的任意門。它讓開發者可以非常輕易地存取和使用成千上萬個預先訓練好的 AI 模型。
- **在這個專案中**：我們透過它的 `pipeline` 函式，載入了兩個用於文本分類的 AI 模型 (`roberta-base-openai-detector` 和 `Hello-SimpleAI/chatgpt-detector-roberta`)，這些模型就是判斷文字是 AI 還是人類寫的關鍵大腦。

#### 4. `torch`
- **它是什麼？**：一個底層的深度學習框架 (由 Facebook 開發)。您可以把它想像成是 AI 模型的引擎。
- **在這個專案中**：`transformers` 套件中的模型需要一個引擎來運作，`torch` (PyTorch) 就是我們選擇的那個引擎。雖然我們沒有直接寫 `torch` 的程式碼，但它在背後默默地支撐著 AI 模型的運算。

### 程式碼結構與重要概念解析

#### `st.set_page_config()`
- **作用**：設定網頁的基本屬性，例如瀏覽器分頁上顯示的標題 (`page_title`) 和圖示 (`page_icon`)。這是每個 Streamlit 應用通常做的第一件事。

#### `@st.cache_resource` 和 `@st.cache_data` (快取)
這是 Streamlit 中非常重要的效能優化工具，把它們想像成是程式的「記憶力」。
- **`@st.cache_resource`**：用來記憶那些「載入很慢且不太會改變」的資源。
  - **比喻**：就像一位廚師第一次準備一道功夫菜，需要花 2 小時熬製高湯。他會把高湯先存起來 (`cache`)。之後再做這道菜時，就不用重新熬湯，直接取用即可。
  - **在專案中**：我們用它來裝飾 `load_model()` 函式。AI 模型檔案很大 (數百 MB)，第一次載入會花一些時間。加上這個裝飾器後，模型只會在第一次執行時載入，之後會一直存在記憶體中，讓應用反應更快速。
- **`@st.cache_data`**：用來記憶函式的「輸入與輸出」。如果函式收到的輸入跟上次一樣，它會跳過計算，直接回傳上次的結果。
  - **比喻**：就像你問朋友「1+1等於多少？」，他回答「2」。你再問一次，他不需要重新計算，會直接從記憶中告訴你答案是「2」。
  - **在專案中**：我們用它來裝飾 `run_prediction()` 函式。如果使用者重複分析同一段文字，程式會直接回傳快取住的結果，而不是再跑一次 AI 模型，節省了運算資源。

#### `st.session_state` (會話狀態)
- **作用**：這是 Streamlit 應用的「短期記憶」。Streamlit 的腳本在每次使用者互動（如點擊按鈕）時都會從頭到尾重新執行一次。如果我們想在多次執行之間保存某些變數（例如使用者的輸入、分析結果），就必須把它們存放在 `st.session_state` 這個特殊的物件裡。
- **在專案中**：我們用它來儲存使用者在輸入框 `st.text_area` 中輸入的文字，以及 AI 分析後的結果，這樣即使腳本重新執行，這些資料也不會消失。

#### `st.tabs()`
- **作用**：建立分頁介面，讓不同的功能區塊可以被整齊地收納。
- **在專案中**：我們用它來區分「單筆文字分析」和「批次檔案分析」兩個主要功能。

#### `on_click` 和回呼函式 (Callback)
- **作用**：這是 Streamlit 中處理按鈕點擊事件的現代方法。我們可以為一個按鈕 (`st.button`) 指定一個 `on_click` 參數，這個參數對應到一個函式。當按鈕被點擊時，Streamlit 會去執行那個指定的函式。
- **在專案中**：我們為「開始偵測」、「清除內容」等按鈕都綁定了各自的處理函式，例如 `on_click=analyze_single_text`。這樣做可以讓程式碼的邏輯更清晰。

#### `st.dataframe()` 與 `column_config`
- **作用**：`st.dataframe()` 用來在介面上顯示一個漂亮的表格 (來自 Pandas DataFrame)。而 `column_config` 參數讓我們可以客製化表格中每一欄的顯示方式。
- **在專案中**：在「批次檔案分析」頁面，我們用 `st.column_config.ProgressColumn` 將「AI 可能性」這一欄變成一個進度條，讓機率大小一目了然，更加視覺化。
